About the project

प्रोजेक्ट परिचय

Created by Shiv Yogi. The intended stack combines Telegram Bot API, Cloudflare Workers, GitHub-hosted JSON content, Cloudflare KV, and Google Gemini API.

शिव योगी द्वारा निर्मित। इसकी निर्धारित तकनीकी संरचना Telegram Bot API, Cloudflare Workers, GitHub JSON, Cloudflare KV और Google Gemini API को जोड़ती है।

Documentation describes intended behavior. A feature should be considered active only after it is implemented and tested in the deployed Worker.
दस्तावेज़ अपेक्षित व्यवहार बताते हैं। किसी सुविधा को सक्रिय तभी मानें जब वह तैनात Worker में लागू और परीक्षण की जा चुकी हो।

Availability depends on backend implementation and third-party services.

सुविधाओं की उपलब्धता Backend Implementation और तृतीय-पक्ष सेवाओं पर निर्भर है।

Bilingual experience

Command reference

कमांड सूची

The command catalog is documentation; Worker handlers are required for execution.

कमांड सूची केवल दस्तावेज़ है; उन्हें चलाने के लिए Worker Handlers आवश्यक हैं।

/startStart the bot and choose a language.बॉट शुरू करें और भाषा चुनें।
/helpShow usage guidance.उपयोग संबंधी सहायता दिखाएँ।
/aboutRead about the project.प्रोजेक्ट की जानकारी पढ़ें।
/creatorShow creator information.निर्माता की जानकारी दिखाएँ।
/featuresShow documented features.दर्ज सुविधाएँ दिखाएँ।
/termsRead terms and conditions.नियम एवं शर्तें पढ़ें।
/privacyRead the privacy policy.गोपनीयता नीति पढ़ें।
/languageChange language.भाषा बदलें।
/commandsList available commands.उपलब्ध कमांड देखें।
/contactShow public contact links.सार्वजनिक संपर्क लिंक दिखाएँ।
/feedbackSubmit feedback if handler is enabled.Handler चालू होने पर प्रतिक्रिया भेजें।
/cancelCancel a pending interaction.लंबित प्रक्रिया रद्द करें।

Admin commands: /admin, /stats, /reload, /list, /ai, /broadcast, /backup. These must be restricted server-side to the configured owner ID. Never expose secrets.

Privacy overview

Telegram data

Telegram डेटा

Telegram may provide user IDs, chat IDs, usernames, message text, and update metadata.

Telegram User ID, Chat ID, Username, Message Text और Update Metadata दे सकता है।

Gemini processing

Gemini Processing

When AI is enabled, a prompt may be sent to Google Gemini API to generate an answer.

AI चालू होने पर उत्तर बनाने के लिए Prompt Google Gemini API को भेजा जा सकता है।
