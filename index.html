4. How the AI Question-Answer System Works 4. एआई प्रश्न-उत्तर प्रणाली कैसे कार्य करती है

When a user sends a message to SHIV YOGI BOT on Telegram, the interaction flows through an ultra-fast, serverless processing pipeline: 1. Webhook Ingestion: Telegram instantly dispatches the user's message payload to a Cloudflare Worker edge function running globally close to the user. 2. Context & Language Evaluation: The Worker retrieves the user's saved language preference (English or Hindi) and validates message structure. 3. Google Gemini Processing: The user's query is securely formatted and transmitted to the Google Gemini AI API via an authenticated request. The Gemini model analyzes the prompt, understands semantic nuances, evaluates context, and synthesizes a comprehensive response. 4. Response Formatting & Delivery: The Cloudflare Worker receives Gemini's generation, formats it cleanly into readable Markdown, and transmits it directly back to the Telegram chat. The entire round trip typically takes mere seconds. जब कोई उपयोगकर्ता टेलीग्राम पर शिव योगी बॉट को कोई संदेश भेजता है, तो यह प्रक्रिया एक अत्यधिक तीव्र, सर्वरलेस पाइपलाइन के माध्यम से संचालित होती है: 1. वेबहुक अंतर्ग्रहण: टेलीग्राम उपयोगकर्ता के संदेश पेलोड को क्लाउडफ्लेयर वर्कर एज फंक्शन पर तुरंत भेजता है, जो विश्व स्तर पर उपयोगकर्ता के निकटतम नोड पर चलता है। 2. संदर्भ एवं भाषा मूल्यांकन: वर्कर उपयोगकर्ता की सहेजी गई भाषा प्राथमिकता (अंग्रेजी या हिन्दी) प्राप्त करता है और संदेश संरचना को मान्य करता है। 3. गूगल जेमिनी प्रसंस्करण: उपयोगकर्ता के प्रश्न को सुरक्षित रूप से तैयार कर प्रमाणित अनुरोध के जरिए गूगल जेमिनी एआई एपीआई को भेजा जाता है। जेमिनी मॉडल संदेश का विश्लेषण करता है, संदर्भ को समझता है और एक विचारशील उत्तर तैयार करता है। 4. उत्तर स्वरूपण एवं वितरण: क्लाउडफ्लेयर वर्कर जेमिनी के उत्तर को प्राप्त करता है, उसे साफ-सुथरे मार्कडाउन में प्रारूपित करता है, और टेलीग्राम चैट पर वापस भेजता है। यह पूरी प्रक्रिया आमतौर पर कुछ ही सेकंडों में पूरी होती है।
